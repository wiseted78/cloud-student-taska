# cloud-student-tasks


## Жобаның мақсаты
Студенттердің оқу тапсырмаларын басқаруға арналған қарапайым веб-қосымша жасау. Жоба GitHub арқылы файлдарды сақтауды және GitHub Pages көмегімен сайтты жариялауды үйренуге арналған.

## Қолданылған технологиялар
- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages

## Мүмкіндіктері
- Жаңа тапсырма қосу
- Тапсырманы орындалды деп белгілеу
- Тапсырманы тізімнен жою
- Барлық тапсырмалар санын көрсету
- Орындалған тапсырмалар санын көрсету

## Іске қосу жолы
1. GitHub репозиторийін ашу.
2. `index.html` файлын ашу.
3. GitHub Pages арқылы жарияланған сайтқа кіру.
